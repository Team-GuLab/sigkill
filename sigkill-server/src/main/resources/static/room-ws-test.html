Room 기능 테스트

공통 변수

GLOBAL

1. 게스트 로그인

POST /api/v1/users/guest-login
표시: REST 응답(JSON)
-

2. 방 목록 조회

GET /api/v1/rooms
표시: REST 응답(JSON)
-

3. 방 생성 (REST + WS 후속 처리)

POST /api/v1/rooms + WS connect + SUBSCRIBE
실행 순서:
1) POST /api/v1/rooms로 방 생성 (host는 서버에서 자동으로 Player 참가 처리)
2) 생성 응답에서 roomId 추출
3) /ws 연결
4) /user/queue/errors, /user/queue/pong 구독
5) /topic/room/{roomId} 구독
6) 생성된 roomId를 아래 참가/준비/시작/나가기 입력창에 자동 반영
생성 직후에는 이미 host가 방에 들어가 있으므로 /app/room/join 전송은 필요 없습니다. 
-
-
-

4. 방 참가 (통합 실행)

GET availability + WS connect + SUBSCRIBE + SEND /app/room/join
실행 순서:
1) GET /api/v1/rooms/{roomId}/availability로 참가 가능 여부 확인
2) /ws 연결
3) /user/queue/errors, /user/queue/pong 구독
4) /topic/room/{roomId} 구독
5) /app/room/join 전송
표시: availability REST 요청/응답, join SEND JSON. join 결과는 우측 Room/Error 이벤트 패널에서 확인하세요. 
-
-
-

5. 방 준비 / 해제

SEND /app/room/ready | /app/room/unready
표시: SEND JSON
-

6. 게임 시작

SEND /app/room/start
표시: SEND JSON
-

7. Game 토픽 자동 구독

AUTO SUBSCRIBE /topic/game/{gameId} (on GAME_START)
방장이 START를 눌러 Room 토픽에서 GAME_START 이벤트가 오면, 방에 참가한 모든 사용자 클라이언트가 Game 토픽을 자동 구독합니다.
GAME_START 이후 퀴즈는 서버 오케스트레이터가 자동으로 시작/종료를 진행합니다.
표시: 자동 구독 결과
-

8. 정답 제출

SEND /app/game/submit
QUIZ_START 이벤트를 받으면 gameId, quizId가 자동 반영됩니다.
choiceNumber만 입력해서 제출하면 됩니다. (일반적으로 1~4)
표시: SEND JSON
-

9. 방 나가기 + WS 연결 해제

SEND /app/room/leave + DISCONNECT
표시: SEND JSON
-

10. Ping / Pong 확인

SEND /app/ping | SUBSCRIBE /user/queue/pong
표시: pong 응답은 우측 PONG 패널에서 확인

구독 상태

ROOM / GAME / ERROR / PONG
표시: 수신 이벤트 JSON (마지막 수신 1건)
